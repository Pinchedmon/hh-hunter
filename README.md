# hh-hunter

Локальная программа для поиска работы на hh.ru. Она находит свежие вакансии, Claude оценивает каждую
и пишет сопроводительное письмо под неё, а ты разбираешь их по одной: отправить, переписать или мимо.
Отклики уходят с твоего аккаунта hh неспешно, в человеческом темпе.

Всё работает на твоём компьютере. Ключ, вход в hh, профиль и история хранятся в папке `data/`
и никуда не отправляются, кроме самого hh.ru и Claude API.

## Что нужно

- Google Chrome.
- [uv](https://docs.astral.sh/uv/) — ставит Python и зависимости сам:
  - macOS / Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
  - Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
- Ключ Claude API: [console.anthropic.com](https://console.anthropic.com) → API keys.
  Если у тебя установлен Claude Code, можно и без ключа — программа подхватит его сама.

## Запуск

- macOS / Linux: `./run.sh`
- Windows: двойной клик по `run.bat`

Откроется страница http://127.0.0.1:5188 с мастером настройки:

1. Вставь ключ Claude и проверь подключение.
2. Нажми «Открыть hh.ru» — откроется отдельное окно Chrome. Войди в свой аккаунт сам.
   Это окно не закрывай, пока пользуешься программой.
3. Claude соберёт профиль из твоих резюме на hh. Прочитай его и исправь: письма пишутся только по этим фактам.
4. Укажи город, деньги, формат и ключевые слова — по ним строятся поиски.

## Как пользоваться

- «Найти вакансии» — собирает новые вакансии (не чаще раза в 45 минут).
- «Разбор» — по одной вакансии: оценка, плюсы и риски, письмо, выбор резюме.
  «Отправить отклик» (⌘/Ctrl + Enter), «Переписать» с комментарием или «Мимо» с причиной.
  Причины отказов и твои правки писем Claude учитывает в следующих оценках.
- «Нужен ты» — вакансии с анкетой работодателя, тестом или капчей: их отправляешь руками.
- «Резюме» — какие резюме видны работодателям, и генератор нового резюме под направление.

## Чтобы hh не забанил

Все запросы идут через предохранитель (`hunter/config.py`, блок LIMITS): паузы между запросами,
лимиты в час и в сутки, отклики только с 9 до 21. Если hh показал капчу или ответил ошибкой,
всё встаёт на паузу от 20 минут до 6 часов. Гарантии нет: правила hh против автоматизации,
поэтому каждый отклик подтверждаешь ты.

## Чтобы передать другу

`./share.sh` соберёт `hh-hunter.zip` без папки `data/` — без твоих ключей, входа, профиля и истории.
